Acceptance tests

IDTestPasses when
AT1Wide fetch targets a separate store.--raw-dir routes writes and the manifest into the given directory; the default store is not touched.
AT2Coverage sub-box.coverage_bbox=None reproduces the current composite exactly; a sub-box changes only which periods are masked, never the retained values.
AT3AOI reaches the ring.On a wide synthetic cube, a 90–150 km ring built with the wide AOI has cells beyond the narrow box; built without it, it does not.
AT4Extended grid + geometry audit.All seven rings swept; each row carries cell count, populated octants, imbalance and realised radii.
AT5Verdict logic.All four branches reachable from synthetic share tables; “outermost” keyed on the (inner, outer) pair, not the inner radius.
AT6Benchmark-blind.AST scan of the sweep path (docstrings excluded) finds no benchmark symbol and no benchmark-shaped path literal.
AT7Positive and negative control.An AR(1) source planted in the ring makes Rule B fire; an AR(1) source confined to the footprint does not make Rule B fire — the NOX-015 defect, now covered.
AT-REG-1No regression.Default noxus variance and noxus ring-sweep outputs byte-identical to the committed CSVs.
AT-ERR-1Missing / partial input.Absent wide cube ⇒ message naming the build command; a manifest with failed batches ⇒ refusal, not analysis.

AT7's negative control is the one that matters most: it is the test NOX-015 did not have, and its absence is why that task's pre-registered rule was defective.
