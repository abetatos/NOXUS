Requirements — Subset resampling for the flux-divergence SNR curve

Task ID NOX-019
Feature slug flux-subset-uncertainty
Status spec_ready
Author spec-author
Human approvalpending
Origin Paper critique B5 (2026-08-31): the paper concedes its flux figure is “a description, not a test”.

Summary

Section 9 of the paper reports SNR at N = 1, 2 and 4 as three points with one realisation each and no uncertainty, and says so. That is avoidable at zero acquisition cost. From four retained overpasses there are four distinct subsets of size 1 and six of size 2; computing the estimator over all of them gives a genuine spread at N = 1 and N = 2 and shows whether the dip at N = 2 (0.22 against 0.27) is anything but subset noise. The same resampling applies to the co-location ratio, whose non-monotonicity (2.06 → 2.29 → 1.80) the paper currently flags without being able to quantify. This does not make N = 4 a powered result — nothing can — but it replaces an admitted description with a measured spread, and it is a prerequisite for the realistic-amplitude injection of C3.

Functional requirements

REQ-001When the subset analysis runs, the system shall compute the divergence estimator over every distinct subset of each achievable size from the retained Level-2 overpasses, and report the mean, minimum and maximum of SNR, field noise (MAD) and co-location ratio at each size.
REQ-002The system shall report the number of subsets contributing at each size, and shall state explicitly that the N = 4 point has exactly one realisation and therefore no spread.
REQ-003The system shall render the SNR figure with the measured spread at N = 1 and N = 2 as error bars, superseding the current three-point line, and shall retain the 1/√N reference and both pre-registered thresholds.
REQ-004The system shall not re-issue a detection verdict: the existing non-detection at N = 4 stands unchanged, and this task adds uncertainty to its presentation only.
REQ-005If the retained Level-2 swaths are no longer cached, the system shall refuse with a message naming the missing granules rather than silently re-downloading.

Non-functional requirements

NFR-001No new acquisition if the four swaths remain cached. If they do not, re-acquisition is four granules over the free CDSE route — bounded and small, unlike the 2.3 TB full-record inversion.
NFR-002Deterministic: subset enumeration is exhaustive, not sampled, so no seed is involved and the result is exactly reproducible.

Edge cases

EDGE-001At N = 4 there is one subset. Report it as a point with no error bar and label it as such; drawing a zero-width bar would imply a measured spread of zero.
EDGE-002Subsets are not independent — they reuse the same four granules — so the spread is a descriptive range, not a confidence interval, and every artefact and caption must say so.
EDGE-003If fewer than four swaths survive QA, the achievable sizes shrink accordingly and the artefact records which granules were dropped and why.

Error states

ERR-001Refuse rather than re-download when the cache is cold (REQ-005): a silent multi-gigabyte pull is exactly the failure mode the free-data rule exists to prevent.
ERR-002Refuse if any granule resolves to a host outside the declared free-host allowlist.

Acceptance criteria

AC-001The artefact carries per-size mean, min, max and subset count for SNR, noise and co-location.
AC-002The paper's flux figure shows spread at N = 1 and N = 2, and its caption states that the range is descriptive and the subsets overlapping.
AC-003The paper's claim that the N = 2 dip and the co-location non-monotonicity are unquantifiable is replaced by the measured ranges, or retained with the ranges as evidence.
AC-004No verdict changes anywhere in the paper.
