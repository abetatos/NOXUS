Design — Subset resampling for the flux-divergence SNR curve

Task ID NOX-019
Feature slug flux-subset-uncertainty
Status spec_ready
Author spec-author
Human approvalpending
Origin Paper critique B5 (2026-08-31): the paper concedes its flux figure is “a description, not a test”.

Summary

Section 9 of the paper reports SNR at N = 1, 2 and 4 as three points with one realisation each and no uncertainty, and says so. That is avoidable at zero acquisition cost. From four retained overpasses there are four distinct subsets of size 1 and six of size 2; computing the estimator over all of them gives a genuine spread at N = 1 and N = 2 and shows whether the dip at N = 2 (0.22 against 0.27) is anything but subset noise. The same resampling applies to the co-location ratio, whose non-monotonicity (2.06 → 2.29 → 1.80) the paper currently flags without being able to quantify. This does not make N = 4 a powered result — nothing can — but it replaces an admitted description with a measured spread, and it is a prerequisite for the realistic-amplitude injection of C3.

Approach

Placement

Extends the existing flux-divergence module with an exhaustive-subset driver; the estimator itself is untouched, which is the point — the same code path produces every subset.

Why exhaustive rather than bootstrap

With four granules the subset space is small enough to enumerate completely (4 + 6 + 4 + 1 = 15 subsets across sizes 1–4). Enumeration is exact and needs no seed; a bootstrap here would add sampling noise to an already tiny sample for no gain.

What this does not buy

The subsets share granules, so the spread understates true sampling variability, and no amount of resampling four overpasses produces power against a Tangshan-magnitude source. The task's honest framing is presentational, and the requirements say so (REQ-004). Power comes from C3 (realistic-amplitude injection), which this task is a prerequisite for rather than a substitute.

External dependencies and freshness

Reuses the pinned dependency set in pyproject.toml; no version change is required by this task.

Risks

  • The verdict rule must be committed before the first scoring run, or the result is a chosen verdict rather than a pre-registered one — the defect NOX-015 recorded in its own first pass.
  • Any deviation from the committed estimator would make the comparison to the paper's published numbers invalid; the design imports rather than reimplements.
