Implement in order. Each task is small and independently verifiable. Mark complete by adding class="done" to its <li class="task-item">. Global status lives in tasks.json. Do not start until the task is human_approved.

T1 is a feasibility spike that GATES the build. Mirroring the VIIRS/calendar/nowcast (NOX-011/012/013) T1 pattern, its benchmark-blind, three-way verdict (GO / GO-degraded / NO-GO) on a bounded data subset decides whether the rest proceeds. Because flux-divergence is known to resolve poorly in high-background/complex-wind NE China, a NO-GO honest null is a realistic terminal outcome. Stop and record the verdict before T2.

  1. T1 Feasibility spike — GATES THE BUILD (REQ-015, AC-007, AT7).
    New noxus/fluxdiv/probe.py: probe(cfg) runs the minimal oversample → flux → divergence + V/τ chain on a bounded data subset (a short date range / reduced extent, laptop-feasible) and assesses, benchmark-blind, whether a coherent, physically-plausible, spatially-localised source term appears over the steel cluster at all: (a) does a divergence/source hotspot co-locate with the committed facility footprints, and (b) is the source signal above the field noise? Emit the three-way verdict — GO (coherent source → build full attribution), GO-degraded (partial/noisy but usable → build with caveats), or NO-GO (no coherent local source → honest null; stop, escalate to the developer, ERR-002). Record the verdict, its evidence, and the measured compute/ storage profile to data/derived/fluxdiv/fluxdiv_probe.txt. Stop and record before T2. Requires a small raw-L2 fixture (a few overpasses) — fetched via T2's module on the bounded window, or a committed synthetic fixture for the unit test.
  2. T2 Config + raw-L2 fetch (REQ-001, REQ-012, NFR-001, AC-001).
    Add frozen FluxDivergenceConfig to noxus/config/run.py (resolution, τ + range, wind level, wind/coverage/QA thresholds, freq, seed, subset window, compute-budget knobs; validation per ERR-004). New noxus/data/tropomi_l2.py: fetch_l2(cfg, start, end) searches + downloads S5P_*_L2__NO2___ swath granules over the AOI from the free CDSE OData catalogue (Bearer token; S3 eodata optional), QA-screened, resumable via a manifest under data/raw/tropomi_l2/ (gitignored). Refuses paid sources (ERR-005). Reuse the NOX-002a CDSE token/manifest conventions. Tests: manifest resume, public-only routing, missing-store error (ERR-001), config validation.
  3. T3 Oversampling (REQ-002, EDGE-002/007, AC-002).
    New noxus/fluxdiv/oversample.py: oversample(granules, cfg) accumulates overpasses onto a fine regular grid using the L2 footprints + averaging kernel, at the pre-registered resolution; insufficient coverage → NaN (never interpolated). Tests on a synthetic swath: dense field reconstruction, coverage flag, no fabrication.
  4. T4 Flux field (REQ-003/006, EDGE-003/004, AC-002).
    New noxus/fluxdiv/flux.py: flux_field(tvcd, wind, cfg) = V·u using an effective/plume-level wind from the existing ERA5 store sampled at overpass time; calm days below cfg.wind_min flagged/excluded; wind-level choice recorded. Missing/misaligned ERA5 → ERR-003. Tests: uniform-wind advection, calm-wind flag, wind-level sensitivity.
  5. T5 Divergence + chemical-loss + BLIND guard (REQ-004/005/007, EDGE-005, AC-002/003, AT3).
    New noxus/fluxdiv/divergence.py: source_term(flux, tvcd, cfg) = ∇·F + V/τ, with τ + wind-level swept for sensitivity; returns the emission-rate field. Benchmark-blind: no CREA/market argument anywhere in this path. Write the AT3 guard test (introspect signatures; assert no CREA/market arg; a test passing CREA is rejected, ERR-006) and the operator- correctness test (planted point source recovered; advected background ≈0).
  6. T6 Facility attribution → source series (REQ-008, AC-004, AT4).
    New noxus/fluxdiv/source.py: attribute_to_facilities(E, facilities, cfg) aggregates the emission field over the committed steel-facility footprints (reusing attribution/source.py regional- background subtraction) → a weekly Tangshan steel NOx source series with coverage/ flag columns (schema in design). Tests: source over a footprint → non-zero; source away from all footprints → ≈0.
  7. T7 Post-hoc CREA compare (REQ-009, NFR-004, AC-005, AT5).
    New noxus/fluxdiv/validate.py: compare_to_crea(source, crea, cfg) uses the weekly-resample-then-align convention (align_series, not an exact-date join — the NOX-012 B3 bug) then reuses robust_corr, lead_lag, bh_fdr, block_length byte-for-byte. Runs only after the blind source series exists. Planted-lead + planted-null tests; assert resample-then-align (not exact-date join).
  8. T8 Report incl. honest null + scale + compute profile (REQ-010/011/013/014, NFR-005/008, AC-006/008, AT6).
    New noxus/fluxdiv/report.py: source-term map over the footprints, attributed source series, CREA-comparison table, and an explicit honest-null verdict when no coherent/lifting source is found ("even the best public point-source method cannot separate Tangshan from the NCP background") — with no re-tuning. Every output states the Tangshan ≈13% / Hebei-preferred scale caveat and the measured compute/storage profile. Committable small stats + figures; raw/fine fields gitignored.
