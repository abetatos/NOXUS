Purpose

Acceptance-level scenarios for the flux-divergence attribution. They describe observable behaviour that must hold for the feature to be accepted. Four gates are load-bearing and non-negotiable: the T1 feasibility gate (AT7), the benchmark-blind guard (AT3), the autocorrelation-robust CREA compare (AT5), and the honest-null outcome (AT6). Tests run on small synthetic fields / a bounded fixture — never a full multi-year download.

Test strategy

Verify user-facing CLI behaviour, operator correctness (planted point source vs advected background), the four gates, edge/error handling, public-only routing, and that reused modules and existing commands (including the relative-index pipeline) are unaffected.

Testing style configured for this project

pytest unit + guard tests; synthetic swath/field fixtures with a planted
point source; introspection-based guard for benchmark-blindness; diff-empty
checks for reuse; bounded fixture for the T1 spike.

Test command

uv run pytest        # all tests
uv run ruff check .  # lint

tests/fluxdiv/   (new)
tests/cli/       (CLI smoke for fetch-l2 + flux-divergence)

Acceptance tests

AT1 Raw-L2 fetch from the free CDSE route (resumable) Draft
Related requirements
REQ-001, REQ-012, REQ-013, NFR-001
Scenario
Acquire raw L2 __NO2___ swath over the AOI on a bounded window.
Preconditions
CDSE_* credentials present (by env name); a short date range.
Action
Run uv run noxus fetch-l2 --start ... --end ....
Expected result
S5P_*_L2__NO2___ granules land under gitignored data/raw/tropomi_l2/ with a resumable manifest; provenance records product/processor version; re-running resumes without re-downloading.
Negative expectations
No full-granule global download; no paid endpoint; no secret in logs.
Suggested test location
tests/fluxdiv/test_fetch_l2.py, tests/cli/test_fluxdiv_cli.py
AT2 Operator correctness — planted source recovered, background ≈0 Draft
Related requirements
REQ-002, REQ-003, REQ-004, REQ-005, REQ-006
Scenario
A synthetic TVCD field with a known point source under a uniform advecting wind.
Preconditions
Synthetic swath + a constant wind field.
Action
Run oversample → flux_field → source_term (∇·F + V/τ).
Expected result
A localised positive source term at the planted location; the smoothly advected background integrates to ≈0; τ and wind-level sweeps produce the reported sensitivity, not a single hidden value.
Negative expectations
No source hotspot where none was planted; over-fine resolution does not fabricate structure.
Suggested test location
tests/fluxdiv/test_operators.py
AT3 Benchmark-blind guard — source builder never sees CREA/market Draft
Related requirements
REQ-007, NFR-002, AC-003, ERR-006
Scenario
The divergence/source-field path must be built without reference to the benchmark.
Preconditions
The source_term / attribution functions exist.
Action
Introspect signatures; assert no CREA/market parameter anywhere in the build path; assert operator defaults (resolution, τ, wind level, thresholds) are fixed constants, not derived from any outcome series.
Expected result
Signature/introspection assertions pass; a test that attempts to pass CREA into the builder is rejected by design (ERR-006).
Negative expectations
No parameter selected to maximise the reported CREA correlation; CREA enters only in the post-hoc compare.
Suggested test location
tests/fluxdiv/test_blind_guard.py

AT5 Robust CREA compare (resample-then-align + BH-FDR + lead/lag) Draft
Related requirements
REQ-009, NFR-004, AC-005
Scenario
Does the attributed source relate to / lead CREA under autocorrelation-robust inference?
Preconditions
A source series + CREA, aligned via the weekly-resample-then-align convention.
Action
Run compare_to_crea: robust_corr + lead_lag + bh_fdr. Test on a planted-lead synthetic and a planted-null synthetic.
Expected result
Planted-lead: robust test detects the lead and survives BH-FDR. Planted-null: BH-FDR rejects nothing. Alignment uses resample-then-align, not an exact-date join.
Negative expectations
No exact-date join (the NOX-012 B3 bug); no naive-only significance reported as robust.
Suggested test location
tests/fluxdiv/test_validate.py
AT6 Honest null is a first-class outcome Draft
Related requirements

Negative expectations
