Design — Flux-divergence point-source attribution

Task ID NOX-005
Feature slug flux-divergence-attribution
Status spec_draft

Technical summary

A new noxus/fluxdiv/ package implements the Beirle flux-divergence method as an additive, selectable attribution stage that never replaces the existing relative-index pipeline. A new raw-L2 acquisition module (noxus/data/tropomi_l2.py) provides the native-footprint swath the method needs. The pipeline is:

  1. Raw L2 fetch (REQ-001): pull S5P_*_L2__NO2___ swath granules over the AOI from the free CDSE OData/S3 route (OFFL + RPRO), QA-screened, resumable via a manifest. Distinct from the gridded openEO product (NOX-002a).
  2. Oversampling (REQ-002): accumulate many overpasses onto a fine regular grid, using the L2 footprints + averaging kernel, to build a dense mean-column field per analysis period.
  3. Flux (REQ-003): F = VNO2 · u, with a boundary-layer-representative effective wind from the existing ERA5 store, sampled at the overpass time.
  4. Divergence (REQ-004): ∇·F cancels the smoothly advected regional background and isolates the local source term.
  5. Chemical-loss correction (REQ-005): add the effective sink VNO2/τ so E = ∇·F + VNO2/τ approximates the emission rate; τ and the plume-height/effective-wind choice are reported with sensitivity (REQ-006, EDGE-004/005).
  6. Facility attribution (REQ-008): aggregate E over the committed steel-facility footprints → a Tangshan steel NOx source series.
  7. CREA comparison (REQ-009): only after the blind field is built, reuse the NOX-008 robust modules + weekly-resample-then-align to test correlation/lead.

The whole build is gated by a T1 feasibility spike (REQ-015) that decides, on a bounded data subset and benchmark-blind, whether a coherent localised source term is recoverable at all — a three-way GO / GO-degraded / NO-GO verdict — before the rest is implemented.

Feasibility + cost caveat. The method is known to resolve poorly in high-background/complex-wind NE China (EDGE-001), so a NO-GO is realistic; and fine oversampling + divergence over a multi-year raw swath is compute/storage-heavy (see Compute and storage profile). Both are surfaced here so the developer decides at approval; T1 makes the call cheaply before the full pipeline exists.

Interfaces and contracts

# noxus/data/tropomi_l2.py  (NEW raw-L2 acquisition; FREE CDSE OData/S3 only)
def fetch_l2(cfg: FluxDivergenceConfig, start, end) -> ManifestResult:
    """Search + download S5P_*_L2__NO2___ swath granules over the AOI from the CDSE OData
    catalogue (Bearer token) or the S3 eodata endpoint; QA-screen (qa_value >= 0.75);
    resumable via a manifest under data/raw/tropomi_l2/. Refuses paid sources (ERR-005)."""

# noxus/fluxdiv/oversample.py
def oversample(granules, cfg) -> xr.DataArray:
    """Accumulate overpasses onto a fine regular grid (cfg.resolution) using L2 footprints +
    averaging kernel; return a per-period mean TVCD field. Insufficient coverage -> NaN (EDGE-002)."""

# noxus/fluxdiv/flux.py
def flux_field(tvcd: xr.DataArray, wind, cfg) -> xr.Dataset:
    """F = V_NO2 * u using an effective/plume-level wind (cfg.wind_level) from ERA5 at overpass
    time. Calm days below cfg.wind_min are flagged/excluded (EDGE-003/004)."""

# noxus/fluxdiv/divergence.py  (BLIND: no CREA/market argument anywhere in this path)
def source_term(flux: xr.Dataset, tvcd: xr.DataArray, cfg) -> xr.DataArray:
    """E = div(F) + V_NO2 / tau  (chemical-loss corrected). tau + wind_level swept for
    sensitivity (EDGE-004/005). Returns the emission-rate field, benchmark-blind (REQ-007)."""

# noxus/fluxdiv/source.py
def attribute_to_facilities(E: xr.DataArray, facilities, cfg) -> pd.Series:
    """Aggregate E over the committed steel-facility footprints -> weekly Tangshan steel NOx
    source series; reuse attribution/source.py regional-background subtraction (REQ-008)."""

# noxus/fluxdiv/validate.py  (POST-HOC; REUSES robust_corr / lead_lag / bh_fdr / align_series)
def compare_to_crea(source: pd.Series, crea: pd.Series, cfg) -> CompareResult:
    """Weekly-resample-then-align (align_series), then robust_corr + lead_lag + bh_fdr.
    Never fit; runs only after the blind source series exists (REQ-009, NFR-004)."""

Data model changes

No changes to existing stores. New: a gitignored raw-L2 swath store (data/raw/tropomi_l2/ + manifest); gitignored fine oversampled/divergence fields (data/derived/fluxdiv/); a gitignored steel source parquet + provenance sidecar (schema above); small committable summaries/figures. No migrations.

Compute and storage profile (NFR-008, REQ-014)

Surfaced so the developer can make an informed resource decision at approval. Orders of magnitude, to be confirmed/refined at T1 on the bounded subset:

  • Raw swath storage. Full-granule S5P L2 __NO2___ is ~0.4–0.6 GB per overpass. NOX-002a avoided ~2.2 TB by server-side subsetting; the raw-L2 path keeps native footprints over the AOI window, so per-overpass kept size is far smaller than a full granule but larger than the gridded product — plan for a few tens of GB over the TROPOMI era for the AOI, all gitignored.
  • Oversampling + divergence compute. Fine-grid accumulation over ~3,700+ overpasses × a fine AOI grid is the heavy step; the divergence operator itself is cheap. This is server-class-comfortable for the full multi-year record; a bounded subset (a few weeks / reduced extent) is laptop-feasible and is what T1 and the unit tests use.
  • Mitigation. cfg exposes a subset window and extent so every early task runs cheaply; the full record is never a prerequisite for the T1 gate. The report states the measured profile from T1 so the full-run decision is evidence-based.

Test design

  • Operator correctness (AT2): on a synthetic field with a known point source and a uniform advecting wind, assert oversample → flux → div + V/τ recovers a localised positive source at the planted location and ≈0 in the advected background.
  • Benchmark-blind guard (AT3/NFR-002): introspect the source-field builder signatures to assert no CREA/market argument; assert operator defaults are fixed constants, not derived from any outcome series. A test that attempts to pass CREA is rejected (ERR-006).
  • Facility attribution (AT4): planted source over a footprint → non-zero series; source away from all footprints → ≈0 attribution.
  • Robust CREA compare (AT5): planted-lead synthetic → robust test detects it and survives BH-FDR; planted-null → BH-FDR rejects nothing; alignment uses resample-then-align (assert not an exact-date join).
  • Honest null (AT6): a background-only field → report states no coherent/ lifting source; no re-tuning of resolution/τ/wind to manufacture significance.
  • T1 verdict (AT7): synthetic coherent-source → GO; noisy/partial → GO-degraded; background-only → NO-GO (stops the build, ERR-002).
  • Public-only (AT-ERR-3): requesting a paid source is refused (ERR-005); the fetch targets only the CDSE free route.
  • Edge/error: missing L2 store (ERR-001), missing/misaligned ERA5 (ERR-003), invalid config (ERR-004), coverage/calm-wind flags (EDGE-002/003).
  • Reuse regression (AT-REG-1): reused modules unchanged (diff-empty); existing CLI commands and the relative-index pipeline still behave.

Tests use small synthetic fields + a bounded fixture, never a full multi-year download. Test command: uv run pytest; lint uv run ruff check .. New tests in tests/fluxdiv/.

Risks and trade-offs

  • Expected-hardness (the dominant risk). Flux-divergence resolves poorly in high-background/complex-wind NE China; the divergence may be dominated by advected background with no localised source rising above noise over Tangshan (EDGE-001). An honest null is a likely outcome and is first-class (REQ-010). The delivered value is a disciplined, benchmark-blind answer to "can the best public point-source method separate Tangshan at all?" — a null closes the DL-A revisit condition decisively.
  • Compute/storage cost. Fine oversampling + divergence over a multi-year raw swath is server-class for the full record (see Compute profile). Mitigated by the bounded-subset T1 gate and subset config; the full run is an evidence-based decision after T1. Rejected alternative: committing to the full multi-year download before T1.
  • Raw-L2 access is a new integration. The CDSE OData/S3 raw-L2 route is new (NOX-002a used gridded openEO); the exact per-variable read path (averaging kernel, geolocation) is verified at T1. Risk: product/read-path surprises. Mitigated by verifying on the bounded subset first and reusing the proven CDSE token flow.
  • Deep-review flags. Two apply, surfaced now so they are not a surprise at review (reference/deep-review-policy.md): (a) a new external download integration (data-access category) — the reviewer verifies free-only routing + credential hygiene; (b) a quantitative claim that the attribution lifts the steel-local share above 0 and/or leads CREA (the DL-A condition) — the reviewer applies the escalation ladder to the benchmark-blind and robust-inference guards specifically.
  • Plume-height / τ modelling choices. The 10 m wind and a single τ are approximations; presenting them as exact would overstate precision. Mitigated by reporting sensitivity across wind level and a τ range (REQ-006, EDGE-004/005). Rejected alternative: a single tuned τ/wind chosen to maximise the CREA correlation (forbidden, NFR-002).
  • Scale. Tangshan ≈13% of national steel; the attribution is a cluster signal. Hebei-provincial statistics preferred (NFR-005). Rejected alternative: presenting it as a national NOx/steel estimate.

Rollback plan

The feature is additive: a new noxus/fluxdiv/ package, a new noxus/data/tropomi_l2.py module, new CLI subcommands, a new config dataclass, new gitignored data dirs. Rollback = remove the package + module + subcommand registration + FluxDivergenceConfig, and revert the .gitignore additions. No existing module is modified beyond additive registration, so reverting cannot regress the relative-index pipeline. Gitignored raw/derived fields can be deleted freely; committed summaries can be removed without affecting other stages.
