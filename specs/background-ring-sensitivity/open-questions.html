Open questions

0 blocking. The questions below change scope or interpretation but none prevents implementation from starting once the spec is approved.

Q1 — Should the sweep also vary the partition order? non-blocking

Ring geometry and entry order are two independent ways the ≈0 local share could be manufactured. This spec fixes the order (A5) and varies only the ring.

Default if unanswered: keep the order fixed; open a follow-up task for order sensitivity (e.g. local → regional → meteo, or a Shapley-style order-averaged decomposition, which would remove the order dependence entirely).

Recommendation: accept the default. Two swept dimensions at once would make a positive result ambiguous.

Q2 — Should the ring be wind-sector-masked instead of annular? non-blocking

A physically sharper test: exclude only the downwind sector of the near ring per period, keeping the upwind sector as background. That isolates the plume rather than moving the whole ring outward, and it would preserve azimuthal balance.

Default if unanswered: not in scope. It needs per-period ERA5 wind direction threaded into mask construction — a larger change than this spec's optional-argument approach, and it would break the “vary one thing” discipline.

Recommendation: record as a follow-up. It is the better long-run test if the annular sweep returns inconclusive.

Q3 — What happens to the paper if the verdict is self-subtraction? developer decision

The paper's Section 6.1 headline, its abstract, its synthesis and its conclusion all rest on the ≈0 cluster-local share. A self-subtraction verdict does not restore the signal — the near-null coupling (r = 0.078) is measured independently — but it does remove the mechanism the paper offers for it.

Default if unanswered: T7 stops and escalates rather than auto-editing the paper.

Recommendation: confirm this escalation is what you want before approving, since it is the one path where this task creates more work than it closes.

Q4 — Seasonal split? non-blocking

NO₂ lifetime is 2–3× longer in winter, so plume contamination of the ring should be strongly seasonal. A winter/summer split of the sweep would be a sharp diagnostic.

Default if unanswered: full-record only; the split is cheap to add later from the same CSV if the full-record result is ambiguous.
