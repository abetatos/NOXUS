Implementation plan

Nine tasks, ordered. T1–T2 are the safety net (regression lock + benchmark-blind guard) and must land before any sweep code runs. T7 is the only task that touches real data and it is the one that can overturn the paper.

  1. T1 Regression lock
    Add AT-REG-1: snapshot the committed variance_decomposition.csv and assert noxus variance reproduces it. Must pass before any change to variance.py. (NFR-003)
  2. T2 Thread the ring parameter
    Add the optional ring=None argument to _level_series_for_cube; None keeps the exact SignalConfig path. Re-run T1 — must still pass. (REQ-001, NFR-002/003)
  3. T3 RingSweepConfig
    Add the dataclass to noxus/config/run.py with the fixed ring grid, advection parameters, weightings, and the pre-registered verdict threshold. (REQ-002/003/031, NFR-001)
  4. T4 Ring geometry diagnostics
    In ring_sweep.py: realised max radius, cell count, azimuthal octant counts, imbalance ratio, beyond_advection flag, and equal-octant ring weighting. Tests AT1, AT5, EDGE-001/002. (REQ-003/013/022)
  5. T5 Sweep driver
    sweep_rings(cfg): loop ring × basis × resolution × weighting over the unmodified decompose_from_levels; assemble the tidy frame with raw dr2_local and the clamp flag; write ring_sensitivity.csv. Tests AT2, AT4, AT-ERR-1. (REQ-010/011/012, ERR-001..004)
  6. T6 Controls and verdict rule
    Implement the REQ-031 rule as a pure function of the frame. Add AT3 (planted in-ring plume ⇒ local share rises) and AT3b (footprint-only source ⇒ share flat across rings). These two decide whether the sweep is trustworthy at all. (REQ-020/021/030/031, AC-004)
  7. T7 Real run on the committed cubes
    Run the full sweep. Record the verdict as it comes out. If self-subtraction, stop and escalate to the developer before touching the paper — the correction is larger than a wording change. (AC-001..003)
  8. T8 CLI, figure, findings note
    noxus ring-sweep; analysis/ring_sensitivity.py figure (shares vs inner radius, 36 km marked); plain-language findings note stating the verdict and, if applicable, that the paper needs correction. (REQ-040/041/042)
  9. T9 Validation and review
    uv run pytest, uv run ruff check ., uv run ruff format .; then reviewer against requirements.html. Documentation targets listed in requirements.html § Documentation expectations. (AC-005)

Definition of done

  • All nine tasks complete; AT1–AT7, AT3b, AT-REG-1, AT-ERR-1 green.
  • ring_sensitivity.csv committed with every swept cell present.
  • Verdict emitted by the REQ-031 rule alone and recorded in tasks.json.
  • noxus variance output unchanged.
  • Paper Section 6.2(i) and control C1 updated to report the actual result.
