Requirements — Investment-grade activity nowcast

Task ID NOX-013
Feature slug activity-nowcast-signal
Status spec_draft
Author spec-author
Human approvalpending

Summary

Convert the NOXUS physical activity measurement into an investment-grade weekly nowcast of Tangshan steel activity, expressed as a surprise: the deviation of the satellite-implied activity from an expectation baseline (the feature's own causal seasonal/trend model combined with the last published official print), emitted as a causal z-score that would be tradable at the next session after overpass plus processing latency.

The product is a signal, not a correlation study. Three project findings frame it and are treated as hard constraints rather than open design space:

  • The continuous NO2 residual alone is not a viable feature. NOX-009 measured the steel-local share of NO2 change-variance at ~0 (93–95% regional common-mode; meteo ~0.3–0.5%). The nowcast feature must therefore come from an independent physical proxy or from discrete event markers, with the NO2 residual used only as a contextual covariate.
  • The intended primary physical feature is now unavailable (finding 2026-08-27). The VIIRS thermal-anomaly series over the steel facility footprints (NOX-011) was the intended primary activity proxy, but the NOX-011 real run closed it off: VNF (VIIRS Nightfire — the sensor that measures industrial radiant heat) is licence/pay-gated since 2025 (no longer public), and the free FIRMS active-fire alternative (90,895 detections over 2019–2026) is an honest null for this cluster (NO2↔VIIRS r=−0.05 ns, CREA↔VIIRS r=−0.05 ns). The root cause is physical: FIRMS detections over the AOI — even <2 km from the plants — peak in spring/summer/autumn (Hebei agricultural crop-residue burning) with low FRP (~1.4 MW) and are ~0 in winter, whereas blast furnaces run year-round and are winter-curtailed. FIRMS active-fire therefore does not see the furnaces and is invalid as a steel-activity thermometer here. The nowcast has no valid physical proxy; the former graceful-degradation path (event markers + NO2 covariate) is now the main path.
  • The coupling is continuous, not event-bound, and decoupling over time. NOX-012 concluded (2026-08-22) that the 2023 rolling-r peak is a scan-maximum artefact and that the coupling is continuous with a 2024 intensity-decoupling. This bears directly on how much incremental information any feature can carry.

Triangulation against hard-to-falsify quantities measured outside China (exporter-side iron-ore shipments, Capesize/Baltic freight, coking-coal exports) is used as quality control and a discrepancy-vs-official-statistics diagnostic — not as the goal. The benchmark to beat/complement is the weekly Mysteel/WIND blast-furnace operating-rate survey (the CREA series): the nowcast must show incremental information (earlier or orthogonal) over the incumbent, else no edge exists. An honest null is an acceptable, first-class outcome.

Honest edge caveat (developer decision input, 2026-08-27). With the physical proxy removed, the nowcast now rests entirely on NO2-derived features (discrete event markers + the continuous residual covariate). Both are known to be weak here: NOX-009 measured the steel-local share of NO2 change-variance at ~0 (93–95% regional common-mode), and NOX-012 found the continuous coupling weak and the 2023 peak artefactual. The nowcast's edge over the CREA incumbent is therefore materially weaker than originally scoped, and an honest null (no incremental information) is a likely and acceptable outcome. The developer should weigh this before approving implementation; the T1 feasibility gate exists precisely to make that call on evidence.

Functional requirements

EARS format. IDs are stable references for design, tasks, and tests.

REQ-001 When the nowcast is built, the system shall emit a weekly Tangshan steel-activity surprise series: the deviation of the satellite-implied activity feature from an expectation baseline, at the configured analysis frequency (weekly default).
REQ-002 The system shall compute the expectation baseline causally from (a) the feature's own seasonal/trend model fit on data available strictly before the target period, and (b) the last official activity print (CREA) published and known at that time.
REQ-003 The system shall compute the surprise as feature-activity minus expectation baseline for each period, using only information available at emission time.
REQ-004 The system shall standardise the surprise into a causal z-score using an expanding/rolling mean and standard deviation computed only from prior periods (no in-sample or full-series normalisation).
REQ-005 When emitting a z-score for an overpass/observation, the system shall stamp it as tradable at the next session after overpass + processing latency (a configurable latency), never at or before the observation time.
REQ-006 The system shall align official prints (CREA) to the nowcast timeline in a publication-lag-aware way: a print may only inform the baseline for periods on or after its publication date, using the last print known at each period.
REQ-007 The system shall build the nowcast on the available NO2-derived features: (b) NO2 event/catalyst markers (NOX-004/NOX-012) for discrete curtailment starts/stops as the primary available feature, and (c) the NO2 continuous residual (NOX-003.1) as a contextual covariate. The former primary physical proxy — (a) VIIRS thermal-anomaly activity (NOX-011) — is unavailable (VNF paywalled; FIRMS active-fire empirically invalid for this cluster, finding 2026-08-27) and shall be treated as not selectable; if a valid VIIRS/thermal series is ever supplied later it may re-enter as an optional feature, but the build shall not depend on it.
REQ-008 The system shall run the NO2-feature path as the main path (no physical proxy available), clearly label every run with the feature used and a reduced-power caveat (NOX-009 ~0 steel-local change-variance; NOX-012 weak coupling), and record which feature was selected. If neither the events nor the residual covariate is available, it shall error per ERR-001.
REQ-009 The system shall produce a triangulation quality-control diagnostic that cross-checks the nowcast against independent, out-of-China quantities (exporter-side iron-ore shipments, Capesize/Baltic freight, coking-coal exports) at their native cadence.
REQ-010 When the nowcast diverges from the official print but agrees with the independent triangulation consensus (or vice versa), the system shall flag the period with uncertainty as a discrepancy, and shall not label any series as "fake" or fraudulent.
REQ-011 The system shall run the incremental-information test vs the CREA incumbent: quantify whether the satellite nowcast surprise carries information about steel activity that is earlier (leads CREA) or orthogonal (adds explanatory content beyond CREA's own causal baseline), using the NOX-008 autocorrelation-robust inference and BH-FDR across the tested configurations. This is the primary acceptance criterion.
REQ-012 The system shall expose the nowcast and its QC/incremental-information diagnostics via the existing noxus CLI pattern (config-driven, resumable/idempotent where a fetch is involved), following the conventions of the existing subcommands.
REQ-013 The system shall write NO2/VIIRS/price-derived nowcast series to gitignored derived paths, and shall emit small committable summary statistics and figures (the nowcast report, incremental-information table, triangulation diagnostic).
REQ-014 The system shall report an honest null as a first-class outcome: if no available feature shows incremental information over CREA, the report shall state that no tradable edge exists, without discarding or re-tuning to manufacture one.
REQ-015 Before the build proceeds, the system shall run a feasibility spike (T1) that confirms the physical proxy is unavailable and assesses whether the available NO2 features (events and/or residual covariate) yield any incremental information over CREA, and shall record a go/no-go verdict before any downstream task runs. Because the VIIRS proxy is closed (finding 2026-08-27), the realistic verdicts are GO-degraded (events + covariate carry some incremental info → build the reduced-power nowcast) or NO-GO (no feature carries incremental info → honest null, stop). The GO-primary (VIIRS) branch is retained only as a dormant path should a valid thermal series ever be supplied.

Non-functional requirements

NFR-001 Strict no-look-ahead. Every baseline, standardisation, and alignment shall be causal: no computation for period t may use data from any period > the information-availability time for t (overpass + latency for the feature; publication date for official prints).
NFR-002 Anti-p-hacking. The expectation baseline / feature model shall be fit without reference to market returns and without tuning against CREA or returns. All detection thresholds, smoothing, and windows shall be fixed as defaults before any incremental-information or outcome statistic is viewed. No parameter may be selected to maximise the reported edge.
NFR-003 Public/free data only, reproducible. All inputs (satellite, benchmark, shipments, freight, coking-coal) shall be public/free; credentials referenced by environment variable name only, never read or logged.
NFR-004 Reuse, do not reimplement. The build shall reuse the NOX-008 autocorrelation-robust machinery (noxus/validation/robust.py: robust_corr, block_permutation_p, bh_fdr, block_bootstrap_statistic), leadlag.py (lead_lag), the NOX-003.1 intensity residual, the NOX-004/NOX-012 event machinery, the NOX-011 thermal series, and the existing config/CLI patterns.
NFR-005 Scale caveat explicit. Every output shall state that Tangshan is ~13% of national steel and that provincial (Hebei) statistics are preferred where available; the nowcast is a cluster signal, not a national estimate.
NFR-006 Determinism. Bootstrap/permutation-based inference shall use a fixed seed so results are reproducible; the seed and all fixed defaults shall be recorded in the output provenance.
NFR-007 Additive, non-breaking. The feature shall not alter the behaviour of existing pipeline stages, CLI commands, or reused modules; it adds new modules/commands only.

Edge cases

EDGE-001 VIIRS thermal series absent (the expected default — VNF paywalled, FIRMS invalid): the nowcast runs the NO2-feature main path and is labelled reduced-power (REQ-008); it does not crash and never fabricates or silently emits a VIIRS-based series.
EDGE-002 Coverage gaps / missing weeks in the feature: never interpolated; the surprise/z-score for those periods is NaN (or marked), not fabricated.
EDGE-003 Variable publication lag of the official print: the last-known print is used per period per REQ-006; a print with an unknown publication date is treated with the configured conservative (maximal) lag.
EDGE-004 Triangulation sources are at a coarser cadence (monthly shipments/exports) than the weekly nowcast: the QC aligns by resampling to a common frequency (never interpolating upward to fabricate weekly values), and reports at the coarser cadence.
EDGE-005 Sparse discrete event markers (few curtailment starts/stops in the degraded path): the incremental-information test reports low power honestly rather than over-claiming.
EDGE-006 Warm-up period: causal expanding baselines emit NaN until the configured minimum history is reached; no z-score is emitted before then.
EDGE-007 Series too short for autocorrelation-robust inference after alignment: the system reports insufficient-power rather than a spuriously significant result.

Error states

ERR-001 If no feature store is available at all (neither VIIRS thermal series, nor NO2 events, nor NO2 residual), the system shall raise a clear error naming the missing inputs and the commands that produce them, and shall not emit a nowcast.
ERR-002 If the T1 feasibility spike returns NO-GO (no feature yields any incremental information over CREA at the fixed defaults), the system shall stop the build and record the honest-null verdict; downstream tasks shall not run.
ERR-003 If the no-look-ahead guard detects that a past emission changed when future data was altered, the system shall fail loudly (test-time), never ship a leaking signal.
ERR-004 If configuration is invalid (e.g. negative latency, unknown feature source, frequency finer than the feature supports), the system shall raise a validation error before any computation.
ERR-005 If a triangulation source is unavailable, the QC diagnostic shall be marked degraded but the nowcast shall still be emitted (QC is not a gate on emission).

Acceptance criteria

AC-001 Running the nowcast command produces a weekly series with surprise and causal z-score columns, latency-stamped emission times, and provenance recording feature source, latency, seed, and fixed defaults. (REQ-001..005, REQ-012, REQ-013)
AC-002 A no-look-ahead guard test proves that altering future feature/print values does not change any previously emitted z-score. (NFR-001, ERR-003)
AC-003 An anti-p-hacking guard test proves the expectation-baseline/feature-model function takes no market-returns argument and no CREA-for-fit argument. (NFR-002)
AC-004 The incremental-information test vs CREA runs with NOX-008 robust inference + BH-FDR and reports lead (does the nowcast lead CREA?) and orthogonality (does it add beyond CREA's own causal baseline?). (REQ-011, NFR-004)
AC-005 With the VIIRS series absent (the default), the nowcast runs the NO2-feature main path, is labelled reduced-power, and records the feature used. (REQ-008, EDGE-001)
AC-006 The triangulation QC diagnostic is produced and, for a constructed divergence, flags the period with uncertainty without labelling any series fraudulent. (REQ-009, REQ-010)
AC-007 When features carry no incremental information, the report states an honest null and no parameter is re-tuned to manufacture an edge. (REQ-014, NFR-002)
AC-008 The T1 spike records a go/no-go verdict — realistically GO-degraded or NO-GO, with GO-primary a dormant branch (VIIRS unavailable) — with its evidence before any downstream task runs. (REQ-015)

UI acceptance criteria

None — this feature has no browser UI. Outputs are CLI, parquet series, small stat tables, and static figures.

Visual evidence

None — no screenshots or mockups are inputs. Figures produced by this feature (nowcast surprise timeline, triangulation overlay, incremental-information plot) are outputs, specified in design.html.

External dependencies and APIs

  • CREA / Mysteel / WIND Tangshan blast-furnace operating rate — already ingested (NOX-001, noxus ingest-benchmark); the incumbent and the official-print input.
  • VIIRS thermal series (NOX-011, VNF/FIRMS) — unavailable (finding 2026-08-27): VNF paywalled since 2025; FIRMS active-fire empirically invalid for this steel cluster (crop-burning-dominated, misses year-round furnaces). Not a feature source for this build.
  • Exporter-side shipments / freight / coking-coal for triangulation QC: candidate public/free sources include Pilbara Ports monthly throughput, Vale production/sales reports, Baltic/Capesize freight indices, and public coking-coal export series. The exact free source per series is an open question (see open-questions.html Q3); a committed CSV snapshot pattern (à la the NOX-012 curtailment calendar) is the safe default.
  • Existing internal features: NO2 intensity residual (NOX-003.1), NO2 events (NOX-004/NOX-012).

Verification evidence (sources, dates, versions) belongs in the design's External dependencies and freshness section.

Memory and decision implications

Candidate decision-log entries (proposed at review time, developer decides):

  • The project product is reframed from a correlation study to an investment-grade surprise nowcast; triangulation is QC, not the goal.
  • The intended independent physical proxy (VIIRS thermal) is unavailable (VNF paywalled; FIRMS active-fire invalid for this cluster, 2026-08-27), so the nowcast leans on NO2 discrete event markers + the residual covariate, at materially reduced power — a consequence of the NOX-009 ~0 change-variance and NOX-011 negative-result findings.
  • Incremental-information-over-CREA is adopted as the acceptance bar for the signal (edge = earlier or orthogonal), with honest-null as a first-class outcome.
