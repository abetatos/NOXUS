Purpose

Acceptance-level scenarios for the nowcast. They describe observable behaviour that must hold for the feature to be accepted. Four guards are load-bearing and non-negotiable: a no-look-ahead guard (AT2), an anti-p-hacking guard (AT3), an incremental-information-vs-CREA test (AT4), and an honest-null test (AT7).

Test strategy

Verify user-facing CLI behaviour, causal correctness, graceful degradation, the four guards, edge/error handling, and that reused modules and existing commands are unaffected.

Testing style configured for this project

pytest unit + guard tests; synthetic fixtures with planted signal/null;
introspection-based guards for anti-p-hacking; diff-empty checks for reuse.

Test command

uv run pytest        # all tests
uv run ruff check .  # lint

Related test files or directories

tests/nowcast/   (new)
tests/cli/       (CLI smoke for the new subcommands)

Acceptance tests

AT1 Weekly surprise + causal z series is produced Draft
Related requirements
REQ-001, REQ-003, REQ-004, REQ-012, REQ-013
Scenario
A feature series and a CREA print are available.
Preconditions
Feature store present (thermal series, or events, or NO2 residual); CREA parquet present.
Action
Run uv run noxus nowcast.
Expected result
A gitignored weekly parquet with columns feature, feature_source, baseline, surprise, z, emission_ts, degraded, warmup; provenance records feature source, latency, seed, fixed defaults, scale caveat.
Negative expectations
No full-series or in-sample standardisation; no interpolated gaps.
Suggested test location
tests/nowcast/test_surprise.py, tests/cli/test_nowcast_cli.py
AT2 No-look-ahead guard Draft
Related requirements
NFR-001, REQ-004, REQ-005, REQ-006, AC-002, ERR-003
Scenario
Emitted z-scores must depend only on information available at emission time.
Preconditions
A built nowcast on a synthetic series.
Action
Mutate future feature/print values (periods > t), rebuild, compare all emissions at periods ≤ t.
Expected result
Every previously emitted z at periods ≤ t is byte-identical; emission_ts is strictly after the observation time (overpass + latency → next session); official prints only inform periods on/after their publication date.
Negative expectations
No past emission changes when the future changes; no expanding-window uses future points.
Suggested test location
tests/nowcast/test_no_lookahead_guard.py
AT3 Anti-p-hacking guard — model never sees market returns or fits to CREA Draft
Related requirements
NFR-002, AC-003
Scenario
The expectation-baseline/feature-model must be fit without reference to returns and without tuning against CREA/returns.
Preconditions
The baseline/feature-model functions exist.
Action
Introspect signatures; assert no market-returns parameter and no CREA-values-for-fit parameter; assert detection thresholds/smoothing/windows are fixed constants (config defaults), not derived from any outcome series.
Expected result
Signature/introspection assertions pass; a test that attempts to pass returns is rejected by design.
Negative expectations
No parameter is selected to maximise the reported edge; the last CREA print may be READ into the baseline but is never a fit target.
Suggested test location
tests/nowcast/test_anti_phacking_guard.py
AT4 Incremental-information vs CREA (robust + FDR) Draft
Related requirements
REQ-011, AC-004, NFR-004
Scenario
Does the nowcast lead CREA or add orthogonal content beyond CREA's own causal baseline?
Preconditions
Nowcast z + CREA aligned weekly (resample-then-align convention).
Action
Run incremental_information: lead_lag for "earlier" + partialled residual robust_corr for "orthogonal", with bh_fdr across the config grid. Test on a planted-lead synthetic and a planted-null synthetic.
Expected result
Planted-lead: robust test detects the lead and survives BH-FDR. Planted-null: BH-FDR rejects nothing.
Negative expectations
No naive-only significance is reported as robust; effective-N/Newey-West applied.
Suggested test location
tests/nowcast/test_incremental.py
AT5 NO2-feature main path runs (VIIRS unavailable, the default) Draft
Related requirements
REQ-007, REQ-008, AC-005, EDGE-001

Suggested test location

AT6 Triangulation QC flags divergence with uncertainty Draft
Related requirements
REQ-009, REQ-010, AC-006
Scenario
A constructed period where the nowcast + external consensus diverge from the official print.
Preconditions
Nowcast series + committed triangulation snapshots (monthly) present.
Action

Expected result

Negative expectations

Suggested test location
tests/nowcast/test_triangulation.py
AT7 Honest null is a first-class outcome Draft
Related requirements
REQ-014, NFR-002, AC-007

Action

Expected result

Negative expectations

Suggested test location

AT8 T1 feasibility spike emits a go/no-go verdict (GO-degraded / NO-GO) Draft
Related requirements
REQ-015, AC-008
Scenario
Feature availability and any-incremental-info are assessed before the build; the VIIRS proxy is unavailable.
Preconditions
Synthetic scenarios: NO2 events informative (→ GO-degraded); nothing informative (→ NO-GO); plus a dormant-branch scenario where a valid thermal series is explicitly supplied (→ GO-primary) to prove the branch exists but is not depended on.
Action
Run uv run noxus nowcast --probe.
Expected result
Verdict is GO-degraded / NO-GO for the realistic scenarios (and GO-primary only when a valid thermal series is supplied), with evidence written to data/derived/nowcast_probe.txt; NO-GO stops the build (ERR-002).
Negative expectations
The build does not proceed past T1 on a NO-GO; the probe never reports GO-primary from FIRMS/absent VIIRS.
Suggested test location
tests/nowcast/test_probe.py
