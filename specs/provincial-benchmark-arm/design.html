Technical summary

Everything this task needs already exists. align_series resamples and inner-joins a feature to a target with a coverage screen; robust_corr returns the full autocorrelation-robust set; the NOX-013 probe already wires features to a target and writes a findings note. The only genuinely new logic is the paired contrast (REQ-012) — a bootstrap CI on the difference between two correlations measured on the same feature over the common sample — and the four-branch verdict rule.

The design's real work is discipline, not machinery. This is the project's first task that deliberately reads multiple targets, so the anti-p-hacking guarantee shifts from “structurally cannot see the benchmark” (NOX-009's guarantee) to “sees all targets, refits nothing, corrects across the whole family, and commits its verdict rule in advance”. The interfaces below are shaped to make the weaker guarantee testable: features are loaded through a read-only accessor with no fitting entry point, and every computed pairing is appended to the family before any is inspected.

The paired-difference bootstrap matters. Comparing two correlations by checking whether their separate CIs overlap is a well-known error; because both use the same NO₂ feature over an overlapping window, the difference has far lower variance than either margin suggests, and a moving-block bootstrap over the joint sample is the right estimator.

Test design

IDTestMethod
AT1Targets loaded; cadence aggregated downSynthetic weekly feature vs a 10-day target; assert both sides are resampled to monthly and that no NaN is filled anywhere (compare against a hand-computed join).
AT2No feature refitAssert the feature accessor exposes no fit/tune entry point, and monkeypatch every signal fitting function to raise — a full run must complete.
AT3Paired contrast recovers a planted differenceConstruct x, y_a (weak link) and y_b (strong link) with known correlations on an AR(1) fixture. Assert the difference CI excludes zero and brackets the true difference, and that it is narrower than the naive interval implied by the two marginal CIs.
AT4BH family completenessAssert family_size equals the number of computed pairings including refused ones, and that removing a pairing from the frame changes the adjusted p-values (i.e. correction is genuinely family-wide).
AT5Lag-reporting disciplineFixture whose CCF peaks at ±max_lag and below its bound; assert peak_is_boundary and peak_significant=False are set and the findings text does not claim a lead or lag.
AT6Verdict rule — all four branchesTable-driven synthetic frames; assert each branch fires, and that changing pipeline_suspect_abs_r in config moves the boundary (threshold not inlined).
AT7Arm-B gateProbe stubbed GO ⇒ Arm-B rows present and folded into the family; stubbed NO-GO ⇒ Arm A only, gap recorded, and a licence-gated route is never substituted.
AT8Sub-period split and caveatsAssert full-record and both sub-periods are emitted, and that the findings note contains the EDGE-005 (processor-version) and EDGE-006 (13%-of-national) statements.
AT-ERR-1Error statesMissing auxiliary parquet ⇒ message naming noxus ingest-benchmark; overlap < 26 ⇒ refused row with reason, still counted in family_size.

Risks and trade-offs

RiskLevelMitigation
Reading multiple targets weakens the project's anti-p-hacking guaranteeHigh likelihood, high impactThe structural guarantee is impossible here by construction, so it is replaced by three testable ones: features read-only and never refit (AT2), family-wide BH including refused pairings (AT4), verdict thresholds fixed in config before T-run and checked in review against git history.
All Arm-A targets share the CREA/WIND publisherCertain, medium impactCannot be mitigated within Arm A. REQ-022 requires it stated as a limit; Arm B exists precisely to add an independent publisher, and its absence (if NO-GO) is reported, not hidden.
A national correlation is driven by shared secular trend, not co-movementHigh likelihood, high impactEDGE-003: contrast computed on the deseasonalised/differenced features, plus a mandatory sub-period split. EDGE-005: the processor-version confound is restated in the findings note.
A scale-confirmed verdict is over-read as “TROPOMI measures national steel”MediumEDGE-006: the findings note must state the correct reading — a Tangshan-AOI signal tracking national output means the AOI signal is regionally dominated, which is the paper's claim, not a national-scale capability claim.
Comparing two correlations via overlapping marginal CIsMedium likelihood, high impactREQ-012 mandates a paired-difference bootstrap; AT3 asserts it is narrower than the naive marginal comparison, so the wrong method cannot pass silently.
Arm B balloons into a data-acquisition projectMediumHard T1 gate (REQ-030) before any fetcher is written; NO-GO is an accepted, reportable outcome (ERR-003), matching the NOX-005/NOX-011 precedent.

Rollback plan

Fully additive. Rollback is: delete noxus/validation/scale_contrast.py, noxus/validation/paired_corr.py, noxus/data/nbs.py, analysis/scale_contrast.py, the two test modules, the ScaleContrastConfig block and the CLI subcommand. No existing module is edited and no committed artefact is overwritten — the task writes only scale_contrast.csv and its findings note.
