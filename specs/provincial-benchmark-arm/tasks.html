Implementation plan

Nine tasks. T1 is a live feasibility gate that may close Arm B before any code is written for it. T2–T3 build the one new estimator and lock the anti-p-hacking guarantees before any target is scored, which is the ordering that matters most in this task.

  1. T1 Arm-B feasibility probe (GATE)
    Resolve live whether NBS Hebei-provincial and national monthly crude-steel output are reachable through a free, public, programmatic route. Emit GO/NO-GO with the route tried and the realised span/cadence. NO-GO closes Arm B and is a valid outcome — no paywalled substitute (REQ-030/031, ERR-003).
  2. T2 Paired-difference estimator
    paired_corr_difference(): moving-block bootstrap CI on r(x, y_b) − r(x, y_a) over the jointly observed sample, reusing the NOX-008 block rule. Test AT3, including the assertion that the paired CI is narrower than the naive marginal comparison. (REQ-012)
  3. T3 Anti-p-hacking guarantees
    Read-only feature accessor with no fit entry point; family accumulator that appends every computed pairing (including refused) before any inspection. Tests AT2 and AT4 must pass before T5 runs. (NFR-001/002, ERR-004)
  4. T4 ScaleContrastConfig + target loading
    Config with targets, features, cadences, sub-periods and the REQ-021 thresholds. Load the three CREA national series from benchmark_auxiliary.parquet; aggregate both sides down for the 10-day series, never interpolate. Tests AT1, AT-ERR-1. (REQ-001/002, EDGE-002)
  5. T5 Scoring and BH family
    Score every feature × target × cadence × sub-period pairing with robust_corr; compute the paired contrast against the Tangshan target; apply BH across the whole family and print the family size. Tests AT4, AT5. (REQ-010/011/013)
  6. T6 Verdict rule
    Implement REQ-021 as a pure function of the frame, with all four branches driven by config thresholds. Test AT6. (REQ-020/021)
  7. T7 Arm B (only if T1 = GO)
    noxus/data/nbs.py fetcher + ingest; fold Arm-B pairings into the same family with the family size updated. Test AT7. If T1 = NO-GO, skip and record the provenance gap. (REQ-032)
  8. T8 Real run, CLI, figure, findings
    Run the contrast on committed data; record the verdict as it comes out. noxus scale-contrast; the r-vs-scale figure; findings note carrying the verdict, the REQ-022 statement of limits, and the EDGE-005/006 caveats. Test AT8. (REQ-040/041/042)
  9. T9 Validation and review
    uv run pytest, uv run ruff check ., uv run ruff format .; reviewer against requirements.html, with an explicit check that the REQ-021 thresholds are unchanged in git history since before T8 ran. (AC-005)

Definition of done

  • T1 GO/NO-GO recorded in tasks.json with the route tried.
  • AT1–AT8 and AT-ERR-1 green; AT2/AT3/AT4 green before T5 ran.
  • scale_contrast.csv committed with every pairing, including refused ones, and the family size.
  • Verdict emitted by the REQ-021 rule alone; thresholds provably unchanged since before the run.
  • Paper control C2 replaced by the result; §7.1 and §8 updated.
