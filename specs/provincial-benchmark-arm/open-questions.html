Q1 — Is Arm B in scope at all? blocking

Arm B (NBS Hebei/national monthly crude steel) is what adds an independent publisher and therefore what actually attacks the feature-vs-target ambiguity. Arm A alone tests spatial scale but leaves every target sourced from CREA/WIND.

Against it: NBS access is a new acquisition path with an unknown free/programmatic route, and it is the part of this task that could turn into a data-engineering project.

Options: (a) run T1 as specified — probe first, build only on GO; (b) Arm A only, and record the provenance gap as permanent; (c) Arm B first, treating provenance as the primary objective and scale as secondary.

Default if unanswered: (a). The probe is cheap and a NO-GO costs almost nothing.

Recommendation: (a). But confirm, because if you would not act on a NO-GO by looking for another independent publisher, option (b) is more honest and saves T1 and T7 entirely.

Q2 — Should the primary national target be the BF rate or crude-steel output? non-blocking

The spec makes the weekly BF Starting Rate (247) primary because it matches the Tangshan target's variable and cadence exactly, so the contrast isolates scale alone. Crude-steel output is physically closer to what a nowcast would want to predict, but it is 10-day and a different variable, so a difference could reflect either.

Default if unanswered: BF rate primary, output series secondary and reported.

Recommendation: accept the default; both are reported regardless, so nothing is lost.

Q3 — Enlarge the NO₂ AOI to province/national scale? non-blocking

The decisive version of the pipeline test would compute NO₂ over Hebei or China and check the pipeline recovers the known national link. That is out of scope here: a Hebei-scale cube is roughly 15× the AOI area and needs the full 2,641-overpass record re-acquired at a wider window.

Default if unanswered: out of scope; recorded as a follow-up task.

Recommendation: accept. Run the cheap contrast first — if it returns pipeline-suspect, that is the moment to justify the larger acquisition.

Q4 — How should a scale-confirmed verdict change the paper's title? developer decision

A confirmed scale contrast would turn the paper's central claim from “we could not find the signal” into “we located the boundary: the signal exists at regional scale and dissolves at cluster scale” — a stronger and more publishable framing than five nulls.

Default if unanswered: report the result; leave the framing decision to the developer.
