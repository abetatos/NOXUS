Summary

The paper's near-null has two live explanations and the project has never run the test that separates them.

  • Explanation A (the paper's). The binding constraint is spatial: the Tangshan cluster term is not separable from the regional common mode, so a cluster-specific benchmark cannot be tracked.
  • Explanation B. The pipeline is broken, or the CREA trader survey is a poor measure of physical output. Either would produce the same near-null and the paper could not tell the difference.

Scoring the same benchmark-blind NO₂ features against wider-scale steel activity discriminates them, because the two explanations make opposite predictions:

ObservationImplies
Tangshan NO₂ tracks national steel activity better than it tracks Tangshan's own BF rate Supports A. The NO₂ signal is carrying a regional/national common mode, which is precisely the paper's claim. It also weakens the feature-vs-target objection: the feature is measuring something real about steel, just not at cluster scale.
Tangshan NO₂ tracks national activity no better than the Tangshan BF rate, and both are near-null Supports B, or at least does not support A. The problem is upstream of scale, and the paper's spatial interpretation is not established.
Tangshan NO₂ tracks the Tangshan BF rate better than the national series Neither — but it would falsify the regional-common-mode reading and require a rewrite.

This is a positive control on the interpretation, not on the machinery, and that is what makes it worth more than its cost. NOX-011 (VIIRS) was the project's previous attempt to break the feature-vs-target ambiguity and it failed for instrument reasons. This route does not depend on a new instrument.

Scope: two arms, one gated

Arm A (mandatory, zero acquisition). Score the existing NO₂ features against the CREA national series already committed in data/derived/benchmark_auxiliary.parquet. Measured read-only on 2026-08-28:

SeriesCadencen since 2019SpanRole
China: Blast Furnace Starting Rate (247)weekly3832018-03 → 2026-06Primary. Same variable and same publisher as the Tangshan BF rate, national 247-mill sample. The cleanest possible scale contrast: only the spatial extent of the target changes.
China: Estimated Daily Average Output: Crude Steel10-day2602009-01 → 2026-05Secondary. Physical output rather than a rate.
China: Estimated Daily Average Output: Pig Iron10-day2602014-06 → 2026-05Secondary. Closest to blast-furnace activity specifically.

Arm B (gated behind a T1 feasibility probe). NBS Hebei-provincial and national monthly crude-steel output. This adds an independent publisher, which Arm A does not: all three Arm-A series come from CREA/WIND, so Arm A holds the spatial scale test but does not fully break the provenance ambiguity. Arm B is attempted only if the T1 probe finds a free, public, programmatic route; if not, the task reports Arm A and records the gap honestly.

Explicitly out of scope. Enlarging the NO₂ AOI to province or country scale. That would test whether the pipeline reproduces the known national NO₂–industry link, which is a different (and much more expensive) question: a Hebei-scale cube is roughly 15× the current AOI area and requires re-acquiring the full 2,641-overpass record at a wider window. It is recorded as a follow-up, not attempted here.

Functional requirements

EARS format.

Targets

REQ-001When running the scale-contrast screen, the system shall load the national CREA series from the committed benchmark_auxiliary.parquet and expose each as a scoring target alongside the existing Tangshan BF rate, reusing noxus.validation.preprocess.align_series unchanged.
REQ-002When a target's native cadence is coarser than weekly (the 10-day output series), the system shall aggregate both sides to the coarser common cadence (monthly) rather than interpolating the target up, and shall record the cadence used per pairing (no interpolation anywhere, EDGE-002).
REQ-003The system shall score the identical NO₂ feature set already used against the Tangshan benchmark — the background-corrected residual (no2_corrected) and the intensity-decomposition covariate (residual_activity) — with no re-tuning, re-fitting or re-selection of any feature parameter for the new targets (NFR-001).

Scoring and the scale contrast

REQ-010For every (feature × target) pairing, the system shall report the full autocorrelation-robust set from noxus.validation.robust.robust_corr: r, n, n_eff (first-order and Newey–West), moving-block bootstrap 95% CI, block-permutation p, and the block length used.
REQ-011The system shall apply a Benjamini–Hochberg FDR correction across the whole pairing family (all features × all targets × lag-0), and shall report the family size explicitly. Adding targets adds tests, and the correction must absorb that (EDGE-004).
REQ-012The system shall report the scale contrast as the headline statistic: for each feature, r against the Tangshan target beside r against each national target, with the difference and a bootstrap CI for the difference (paired over the common sample, so the comparison is not two independent CIs eyeballed against each other).
REQ-013The system shall report a cross-correlation over the same fixed ±8-period window used elsewhere, and shall mark any peak that (a) fails its per-lag significance bound or (b) sits at the scan boundary, as not an estimated lag — the reporting discipline established by the paper's Section 6.5 correction.

Pre-committed verdict rule

REQ-020The system shall emit one of: scale-confirmed (national coupling robustly exceeds Tangshan coupling), no-scale-effect (both near-null, difference CI contains zero), pipeline-suspect (national coupling is also near-null and materially below the published national-scale literature range), or inverted (Tangshan exceeds national).
REQ-021The verdict rule, fixed before any result is viewed: scale-confirmed requires the national pairing to be robust-significant (BH-adjusted permutation p < 0.05) and the paired difference CI (REQ-012) to exclude zero, for the primary national target (BF Starting Rate 247) on at least one feature; inverted is the mirror condition; no-scale-effect when neither pairing is robust-significant and the difference CI contains zero; pipeline-suspect when neither is significant and the national |r| is below 0.2 — well under the 0.5–0.75 range the national-scale nowcasting literature reports.
REQ-022The system shall state, in the findings note, which of the paper's two explanations the verdict supports and what it does not establish — in particular that a scale-confirmed verdict from Arm A alone does not break the provenance ambiguity, because all Arm-A targets share the CREA/WIND source.

Arm B (gated)

REQ-030Before any Arm-B acquisition, the system shall run a T1 feasibility probe that resolves, live: whether an NBS (National Bureau of Statistics of China) monthly crude-steel series for Hebei and for the nation is reachable through a free, public, programmatic route with no licence gate; the probe shall report the route, the realised series span and cadence, and a GO/NO-GO.
REQ-031If the probe returns NO-GO, the system shall report Arm A alone and record the provenance gap explicitly as an unresolved limitation. It shall not substitute a paywalled or licence-gated source (the free/public-data principle, as with VIIRS Nightfire in NOX-011).
REQ-032If the probe returns GO, Arm B shall be scored under the identical REQ-010..013 machinery and folded into the same BH family, with the family size updated.

Reporting

REQ-040The system shall write data/derived/scale_contrast.csv (one row per feature × target × cadence) and a plain-language findings note carrying the verdict, the driving numbers, and the REQ-022 statement of limits.
REQ-041The system shall emit a figure comparing r with its CI across targets, ordered by spatial scale (Tangshan cluster → province, if available → national), so the scale contrast is visible as a trend rather than a table lookup.
REQ-042The system shall expose the screen as a noxus subcommand driven by a recorded config, following the NOX-013 probe wiring. Existing subcommands and their defaults are unchanged.

Non-functional requirements

NFR-001No feature re-tuning. The NO₂ features are consumed exactly as committed. Introducing new targets must not become an opportunity to re-select a feature that flatters one of them — the anti-p-hacking risk is higher here than in a benchmark-blind task, because this task by construction reads targets.
NFR-002Family-wide multiplicity. Every pairing computed enters the BH family, including ones that return nulls. No pairing may be computed, seen, and then omitted from the correction.
NFR-003Additive. No existing estimator or feature is modified; align_series, robust_corr and the lead-lag machinery are reused read-only.
NFR-004Deterministic. Fixed seed, 5,000 bootstrap and permutation draws, matching the project standard.
NFR-005Free and public only. Arm B may not use a licence- or pay-gated source (REQ-031).

Edge cases

EDGE-001Shared publisher. All three Arm-A targets are CREA/WIND, as is the Tangshan benchmark. A correlated survey artefact would move all four together. Handled by REQ-022 (stated as a limit) and by Arm B (independent publisher) where feasible — not by pretending Arm A is independent.
EDGE-002Cadence mismatch. The 10-day output series cannot be aligned to weekly without interpolation. REQ-002 aggregates both sides down instead; the reduced n must be reported, not hidden.
EDGE-003National series is itself trending. A spurious scale-contrast could arise from two shared secular trends rather than co-movement — exactly the trap the paper's Section 4 “decoupling” discussion documents. The screen shall therefore report the contrast on the deseasonalised/differenced features already used, not on raw levels, and shall report a sub-period split (2019–2021 / 2022–2026) alongside the full record.
EDGE-004Multiplicity inflation. Adding three targets triples the family. REQ-011 requires the family size to be printed so a reader can see what the correction absorbed.
EDGE-005Processor-version confound. Any secular component of a national-scale correlation is confounded with the unharmonised TROPOMI version sequence (paper Section 2). The sub-period split of EDGE-003 partially isolates this; the findings note must repeat the caveat rather than let a national trend correlation stand unqualified.
EDGE-006Tangshan is ~13% of national output. A Tangshan-AOI NO₂ feature correlating with national steel is not evidence that TROPOMI measures national steel; it is evidence that the AOI signal is dominated by something regionally coherent. The findings note must state this reading explicitly.

Error states

ERR-001Missing auxiliary benchmark. If benchmark_auxiliary.parquet is absent, fail with the command that regenerates it (noxus ingest-benchmark).
ERR-002Insufficient overlap. Fewer than min_overlap = 26 common periods for a pairing ⇒ refuse that pairing with a recorded reason; do not emit an unstable estimate. The pairing still counts in the family size.
ERR-003Arm-B route unavailable. NO-GO from the T1 probe ⇒ report Arm A and record the provenance gap (REQ-031). This is a designed-for outcome, not a failure.
ERR-004Feature re-fit attempted. Any code path that would refit a feature against a target is a hard failure, verified by test (AT2).

Acceptance criteria

AC-001noxus scale-contrast runs on committed data and writes scale_contrast.csv with every feature × target pairing, including refused ones.
AC-002The Tangshan rows reproduce the committed NOX-013 numbers (no2_corrected: r = −0.014, n = 364; residual_activity: r = +0.063, n = 379) to floating-point tolerance.
AC-003A paired difference CI is reported per contrast (REQ-012), and a verdict is emitted by the REQ-021 rule alone.
AC-004The T1 Arm-B probe returns an explicit GO/NO-GO with the route it tried, and a NO-GO is reported as a limitation rather than silently dropped.
AC-005Full test suite and ruff check pass; no existing command's output changes.
